# sillytavern-nai-manga-preset

沉浸式在酒馆看漫画
不是文字+图片，而是只有图片

测试模型
反重力gemini3.8f、NovelV5full

功能介绍
剧情推进与漫画生成衔接：通过数据库的剧情推进来生成连续可靠的剧情，从而使漫画分镜与剧情保持流畅。
按页规划与生成：支持固定页数或根据剧情动态生成页数的创作方式。
多种漫画表现选项：可选择生成黑白漫画或者全彩漫画，并且有多种不同的分镜风格、页面留白方式、气泡与对白规则。
角色与画面连续性：预设包含角色身份、外貌、穿搭和出场表现等约束；重绘页面时，脚本会读取同一轮其他页面作为参考，帮助保持角色、服装、场景和剧情衔接。
逐页重绘：双击图片立即重画，长按图片进入提示词工作台，可自行修改提示词，可附加重绘要求重roll本页提示词
画风管理：脚本提供画风提示词管理；画风条目可拆分固定正面词与负面词，并与页面提示词组合后提交。直接在预设页修改并保存，就可以把提示词同步进脚本
自动切换尺寸：预设会根据情节起伏自动切换尺寸，制作出跨页漫画
生成过程管理：支持页面任务状态显示、排队与并发控制、停止生成，以及连接配置管理；也提供多组绘图连接配置和账号轮换选项
剧情推进美化与重roll功能：剧情推进直接完美折叠在用户层，保证沉浸式观看体验，并提供剧情推进重 roll 操作
数据库配套模板：可从脚本面板直接导入漫画表格模板和剧情推进预设，配合数据库管理剧情与角色资料
